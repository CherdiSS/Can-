# Неоновый Побег

Мобильная браузерная 2D-игра-погоня на выживание (вид сверху) на **Phaser 3** с **Arcade Physics**.
Ты — девушка-врач. Убегай от трёх пациентов, обходи препятствия и собирай жёлтые таблетки-бонусы.
Все персонажи — пиксель-арт в больничной теме.

- Чистый HTML5 + CSS3 + JavaScript ES6+, без сборщиков и npm-зависимостей.
- Phaser 3 подключается с CDN (`cdn.jsdelivr.net`), поэтому при первом запуске нужен интернет.
- Вертикальный экран 9:16, рассчитан на iOS Safari и Android Chrome; на компьютере тоже работает.

## Управление

| Устройство | Как играть |
|------------|------------|
| Телефон    | Джойстик в отдельной панели внизу экрана (не закрывает арену). Коснись его и двигай ручку: чем дальше от центра, тем быстрее движение. Палец можно уводить за край джойстика — направление продолжает считываться. |
| Компьютер  | `WASD` или стрелки. Пауза — `Esc` или `P`. В меню `Enter`/`Пробел` — начать игру. |

## Правила

- +10 очков за каждую полную секунду выживания.
- +100 очков за каждую жёлтую таблетку.
- Касание пациента — поражение.
- Сложность растёт:
  - **0–20 с** — враги на базовой скорости (94%, 90% и 82% от скорости игрока);
  - **20–50 с** — скорость и манёвренность врагов плавно растут, но постоянная скорость никогда не выше 97% от скорости игрока;
  - **после 50 с** — враги делают короткие рывки (с предупреждением: мигание и линия рывка), рывки становятся чаще; бонусы исчезают через 5 секунд.
- Враги — пиксельные пациенты; роль видна по силуэту и цвету контура:
  - **Охотник** (красный контур, пациент со шприцем) — гонится прямо за тобой, очень поворотлив;
  - **Перехватчик** (пурпурный контур, пациент с капельницей) — целится в точку впереди тебя;
  - **Тяжёлый загонщик** (оранжевый контур, пациент в бинтах и гипсе) — медленный, отрезает путь к бонусу.
- Лучший результат сохраняется в `localStorage` браузера.

## Играть по ссылке (GitHub Pages)

Игра — статический сайт, её можно открыть на iPhone/Android просто по ссылке.

1. На GitHub: репозиторий → **Settings → Pages**.
2. **Source:** «Deploy from a branch», ветка с игрой, папка `/ (root)` → **Save**.
3. Через 1–2 минуты игра доступна по адресу `https://cherdiss.github.io/Can-/`.

Для приватного репозитория GitHub Pages доступен только на платном тарифе GitHub.
На iPhone в Safari можно нажать «Поделиться» → «На экран „Домой“» — игра будет запускаться с иконки почти на весь экран.

## Запуск на компьютере

Игру нужно открывать через локальный веб-сервер (а не двойным щелчком по `index.html`).

**Вариант 1 — Node.js** (нужен установленный Node.js):

```bash
git clone https://github.com/CherdiSS/Can-.git
cd Can-
npx serve .
```

Откройте адрес, который покажет команда (обычно `http://localhost:3000`).

**Вариант 2 — Python** (если Node.js нет):

```bash
cd Can-
python3 -m http.server 8000
```

Откройте `http://localhost:8000`.

Совет: в Chrome откройте инструменты разработчика (`F12`) и включите режим устройства (`Ctrl+Shift+M`), чтобы увидеть игру как на телефоне.

## Как открыть игру на телефоне (одна Wi-Fi-сеть)

1. Подключите компьютер и телефон к **одной и той же** Wi-Fi-сети.
2. Запустите сервер на компьютере (`npx serve .` или `python3 -m http.server 8000`).
   `npx serve` сам напишет строку `Network: http://192.168.x.x:3000` — это и есть нужный адрес.
3. Если адрес не показан, узнайте IP-адрес компьютера:
   - Windows: команда `ipconfig` → строка «IPv4-адрес»;
   - macOS: `ipconfig getifaddr en0`;
   - Linux: `hostname -I` или `ip addr`.
4. На телефоне откройте браузер и введите `http://<IP-компьютера>:<порт>`,
   например `http://192.168.1.42:3000`.
5. Держите телефон вертикально.

Если страница не открывается:
- разрешите входящие подключения для Node.js/Python в брандмауэре компьютера;
- проверьте, что телефон не подключён к гостевой сети Wi-Fi (там устройства часто изолированы друг от друга);
- убедитесь, что вводите `http://`, а не `https://`.

## Структура проекта

```
Can-/  (корень репозитория)
├── index.html            — страница, подключение Phaser и скриптов
├── css/style.css         — полноэкранный вертикальный макет, safe-area, запрет жестов
├── assets/sprites/       — пиксельные спрайты (героиня, 3 врага, бонус) и скрипт make_sprites.py, которым они нарисованы
├── js/
│   ├── config.js         — все настройки баланса + функции текста/кнопок
│   ├── main.js           — конфигурация и запуск Phaser
│   ├── scenes/
│   │   ├── BootScene.js  — загружает спрайты
│   │   ├── MenuScene.js  — главное меню
│   │   ├── GameScene.js  — игровой процесс, физика, джойстик, сложность, очки
│   │   └── UIScene.js    — HUD, пауза, экран поражения
│   ├── objects/
│   │   ├── Player.js     — игрок
│   │   ├── Chaser.js     — преследователь
│   │   └── Bonus.js      — бонус
│   └── utils/
│       └── storage.js    — рекорд в localStorage
└── README.md
```

Баланс (скорости, фазы, размеры хитбоксов, расположение препятствий) меняется в `js/config.js`.

## Что можно добавить после MVP

- Звуки и музыка (с кнопкой выключения звука).
- Вибрация при поимке и подборе бонуса.
- Визуальные эффекты: свечение, шлейфы, частицы, лёгкая тряска экрана.
- Разные типы врагов (быстрый «рывок», патрульный, «предсказывающий» движение игрока).
- Усиления: щит, магнит для бонусов, заморозка врагов, ускорение.
- Несколько карт или процедурная генерация препятствий.
- Комбо за быстрый сбор бонусов и очки за «near miss» (опасное сближение).
- PWA: установка на главный экран и работа без интернета (с локальной копией Phaser).
- Таблица лидеров, статистика и достижения.
- Настройки: чувствительность и размер джойстика, режим для левши.
